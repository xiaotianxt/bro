# bro 1.2.0

## Cross-extension debugger recovery

Chromium can reject debugger attachment to a normal website containing another
extension's protected iframe. bro now preserves the original error and adds
`CDP_FOREIGN_EXTENSION` guidance: diagnose first, keep password managers enabled
when needed for login, and pause only with explicit profile-wide authorization.
No automatic disable, page refresh, or input replay is introduced.

New tools:

- `debugger_diagnose`: best-effort frame origins without CDP; missing frames are
  explicitly inconclusive.
- `extensions_status`: exact extension IDs, enabled state, and pending recovery.
- `extensions_pause`: bounded, explicit pause with a durable restoration journal.
- `extensions_resume`: verified restoration using the pause ownership token.

The Pi adapter discovers these together with `CDP extension recovery`. Settings
provides pause/restore controls even if the MCP client has not refreshed its
catalog. A toolbar badge and persistent failure state keep recovery visible.

## Upgrade

**New browser permission: `management`.** Review/approve the permission and reload
the extension. It permits managing other extensions across the browser profile;
it is not tab-scoped. Update the Homebrew server and tagged Pi package together,
then reload Pi. Development-directory installations must rebuild their own
extension output; Homebrew does not replace that directory.

Alarms are a recovery backstop, not a guarantee while bro/browser is disabled or
closed. If re-enable fails, use the browser extension manager. Pausing can leave
an injected iframe until navigation; never silently refresh unsaved user work.

## Validation

The isolated browser regression verifies cross-extension rejection, actionable
MCP error propagation, no automatic pause, access after explicit pause and test
page navigation, renewed rejection after restoration, and alarm recovery.
A real Helium 155 / 1Password comparison verified the same enable/disable causal
sequence, including the need to reload the disposable test page after pausing.
See [extension pause](../extension-pause.md) for the workflow and limitations.
