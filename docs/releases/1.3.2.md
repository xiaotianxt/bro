# bro 1.3.2

## User-script controls

The extension's User scripts list now has one-click Enable/Disable actions and
shows each script's current state. Disabling preserves its source and settings
across browser restarts and extension updates. Editing a disabled script does
not enable it. Reload matching pages to apply changes; disabling does not undo
code that has already run. Agent-facing script listings also report the state.

## Background wheel scrolling

Keep page-focus emulation active through rendering after wheel dispatch, without
activating the tab or window. Results distinguish wheel dispatch from actual
movement, since page handlers and scroll boundaries can prevent scrolling.
Rendering failures report that input was already dispatched, without replay.

## Pi MCP connection lifecycle

Cancellation and request-level failures no longer tear down the shared connection
or interrupt sibling requests. Expired sessions are invalidated for the next
request without replaying actions. Connection setup and session shutdown have
bounded deadlines that close the underlying transport.

## Validation and upgrade

`make check` passed, including extension and Pi client regression tests.
Upgrade the Homebrew package and reload the browser extension. Update the Pi
package to the matching tag and reload Pi to use the client fixes.
