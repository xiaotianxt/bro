# bro v1.1.1 — correct MCP server identity

Fix the MCP initialization response to advertise `bro` and the actual compiled package version instead of the rmcp SDK's default name/version.

This issue was found during the installed v1.1.0 verification: the binary and browser extension were correctly upgraded, but the MCP handshake reported `rmcp 1.7.0`. A regression test now checks the product name and `CARGO_PKG_VERSION`.

No ref/scroll behavior changes are included in this patch. The frame-aware refs and render-synchronized scroll workflows introduced in [v1.1.0](https://github.com/xiaotianxt/bro/releases/tag/v1.1.0) remain unchanged. Upgrade matching server/extension artifacts and reload the agent's tool catalog.
